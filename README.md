# Exp1_S1_lisbeth_bilbao

Actividad Formativa Semana 1 — Desarrollo Frontend II (PFY2202)

Sitio React de **Casa Gourmet** (supermercado) con navegación mediante React Router.

## Pantallas

- `/` — Inicio (Home)
- `/quienes-somos` — Quiénes somos
- `/contactanos` — Contáctanos (con formulario)

Menú inferior fijo con `NavLink` / React Router.

## Cómo ejecutar

```bash
npm install
npm run dev
```
